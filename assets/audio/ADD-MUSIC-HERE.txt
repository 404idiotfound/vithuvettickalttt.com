ADD MORE MUSIC
==============
Every .mp3, .ogg, .m4a or .wav file in this folder is played, in file-name
order. When one track ends the next one starts; after the last, it loops
back to the first. To add a song, just drop the file here and name it with
a number first so you control the order, for example:

    06-my-new-song.mp3

The title shown in the player comes from the file name (the number and the
dashes are removed). Only use music you have the right to publish.
Tip: keep each file under ~3 MB (128 kbps MP3) so the page stays fast.
