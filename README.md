# Vithuvattikal Tic Tac Toe — GitHub Pages edition

Static HTML/CSS/JavaScript version for GitHub Pages. PHP has been removed.

## Features
- Two players or computer opponent
- Character selection, coin toss, sound effects, music player
- Scores saved locally in each browser using localStorage

## Deploy
1. Create a GitHub repository and upload the contents of this folder.
2. In repository Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`, Save.
3. Wait for the deployment and open the Pages URL.

Scores are local to each browser/device and are not shared globally.
