How to play
  1. Each player has only 3 heads.
  2. Take turns putting a head on any empty square.
  3. When all 3 of your heads are down, each turn you slide one head to a free square right next to it.
  4. The first to get 3 heads in a line (row, column or diagonal) wins.
  5. If the same position comes up 3 times, it is a draw.
